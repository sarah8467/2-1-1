# ART:SYN | 예술과 조직의 성장을 연결하는 기업교육 AI Agent

기업 맞춤형 예술교육 제안서 생성 및 검증 프로젝트  
실습 기간: 2026.11.24–25

## 프로젝트 소개

ART:SYN(Art + Synergy)은 기업 교육 의뢰를 분석하여 교육 대상의 직무, 인원, 시간, 예산, 재료 및 교육 목적에 적합한 제안서를 작성하는 AI Agent이다. 예술을 통한 정서적 환기, 창의적 사고, 동료 간 소통을 교육 활동에 연결하며, 기업교육의 실제 운영 가능성과 참여자의 심리적 안전성을 우선한다.

이번 실습에서는 ChatGPT, Claude, Gemini에 동일한 교육 의뢰를 입력하여 결과를 비교하고 Claude를 선정했다. 이후 페르소나 및 Few-shot 예시를 적용하고, 실제 대화에서 인원·시간·예산 변경, 동일 입력 반복, 환각 검증, 프롬프트 개선, 미해결 과업 분석을 수행했다. 별도 소프트웨어 배포가 아닌 대화형 AI 지시 및 검증 실습이다.

## 최종 설계 사례: COLOR LAB — 정답 없는 실험실

| 교육 조건 | 최종 제안 |
|---|---|
| 교육 대상 | 국내 대기업 A사 연구개발직 임직원 |
| 인원 및 그룹 | 48명, 6명×8그룹 |
| 교육 시간 | 90분 |
| 핵심 활동 | 사물 번역 프로젝트: 관찰 → 번역 → 해독 |
| 교육목표 | 알아차림 · 확장 · 연결 |
| 재료비 상한 | 384,000원 (1인당 8,000원) |
| v2 배정안 | 374,400원 (1인당 7,800원), 잔여 9,600원 |

재료비 배정안은 실제 견적이 아닌 조건부 실행안이다. 교육은 감상, 개인 창작, 그룹 공유를 중심으로 구성하며, 심리적 진단이나 치료를 목적으로 하지 않는다. v2에서는 감정 기록과 기업 제출용 익명 설문을 분리하고, 공유를 원하지 않는 참여자를 위한 대체 활동과 작품 포장·반출 절차를 추가했다.

## 실험의 결론

- 명확한 역할, 고정된 출력 형식, 구체적인 검증 기준을 제공하면 반복적인 제안서 작성과 수정 업무의 일관성을 높일 수 있다.
- 자체 검증표가 모든 오류를 방지하는 것은 아니다. 합계뿐 아니라 표와 본문, 단계별 세부 시간, 최신 조건을 교차 검증해야 한다.
- 실제 상품 재고·배송비와 작품 건조·포장 안전성은 문서 생성과 별개인 검증 과업이다. 확인되지 않은 정보는 조건부로 표시한다.

## 기록의 범위

실제 수행한 대화와 그에 근거한 분석을 구분하였다. 일부 초기 응답과 Few-shot 입력 전문은 요약으로 기록했고, 연속된 턴 19–30의 발화 내용을 수록했다. 모델의 정확한 버전·개별 실행 시각은 확인된 범위만 표기했다. U01은 수정 후 재시도까지 진행하였고, U02는 v2 적용과 별도 최초 시도 후에도 해결되지 않았으나 마지막 별도 재시도는 실시하지 않았다. 실제 물리적 시험 및 구매는 수행하지 않았다.
